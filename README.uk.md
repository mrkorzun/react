# ⚛️ React — навчальний репозиторій

Особистий репозиторій для вивчення React. Тут зібрано все, що я проходжу з
React: теорія, практика та задачі для повторного розв’язання, усе в одному місці.

## Як влаштований репозиторій

### `main` — поточне навчання

Сюди я пушу те, що проходжу на курсі прямо зараз. Кожна папка в
`src/components` — це етап навчання у вигляді міні-проєкту: лише практика й
код, без теоретичних пояснень. Список поповнюється в міру проходження.

| Папка                         | Що відпрацьовується                                                        |
| ----------------------------- | -------------------------------------------------------------------------- |
| `src/components/Theory-pr`    | Компоненти й типізовані пропси, варіанти через `clsx`, CSS-модулі, `react-icons` |
| `src/components/Theory-pr2`   | `useState`: компонент `Counter` з незалежним станом у кожного екземпляра   |
| `src/components/Cocktails-pr` | Сторінка коктейлів: вкладені компоненти, рендер списків через `map()`      |
| `src/components/ModalExample` | Модальне вікно: відкриття/закриття через булевий `useState`, передача функції через пропси |

#### `ModalExample` — як працює модалка

**Ідея.** Відкриття й закриття модалки зводиться до одного булевого значення
в стані: `const [isOpen, setOpen] = useState(false)`. `true` — модалка
показана, `false` — прихована. Умовний рендер `{isOpen && <Modal ... />}`
додає її на сторінку або прибирає.

**Технічна специфікація:**

- Стан (`isOpen`) і два обробники живуть в `App`: `handleOpen` →
  `setOpen(true)`, `handleClose` → `setOpen(false)`.
- Кнопка «Open Modal» викликає `handleOpen`.
- `App` передає `handleClose` у `Modal` через пропс `onClose`. Сама модалка
  станом не володіє — вона отримує лише функцію, щоб «попросити» батьківський
  компонент закрити її.
- У `Modal` пропс типізовано через `interface ModalProps { onClose: () => void }`
  і навішано на кнопку закриття: `onClick={onClose}`.
- Верстка: `backdrop` закриває весь екран напівпрозорим фоном, `modal`
  центрується через flexbox; стилі — у CSS-модулях.

## Хочеш розв’язати задачу й показати мені?

Із задоволенням перевірю твоє рішення. Як це зробити:

1. Зроби **Fork** цього репозиторію (кнопка праворуч угорі на GitHub).
2. Склонуй свій форк і перейди в гілку задачі:
   ```bash
   git clone https://github.com/<твій-нік>/react.git
   cd react
   git checkout task-01-cafe-feedback
   git checkout -b task-01-cafe-feedback-<твій-нік>
   ```
3. Розв’яжи задачу за README, закоміть і запуш гілку у свій форк:
   ```bash
   git push -u origin task-01-cafe-feedback-<твій-нік>
   ```
4. Відкрий **Pull Request** у цей репозиторій:
   - **base:** `task-01-cafe-feedback` (гілка задачі, **не** `main`);
   - **compare:** твоя гілка з форку;
   - у назві вкажи: `Рішення task-01 — <твій-нік>`.
5. Я перегляну код і залишу коментарі прямо в PR.

PR **не мерджиться**, щоб гілка задачі залишалася чистою для наступних
проходжень. Після рев’ю я закрию PR, а твоє рішення залишиться у твоєму форку.
