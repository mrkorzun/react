# ⚛️ React — навчальний репозиторій

Особистий репозиторій для вивчення React. Тут зібрано все, що я проходжу з
React: теорія, практика та задачі для повторного розв’язання, усе в одному місці.

## Як влаштований репозиторій

### `main` — поточне навчання

Сюди я пушу те, що проходжу на курсі прямо зараз. Кожна папка в
`src/components` — це етап навчання у вигляді міні-проєкту, який я розв’язую
під час курсу. Список поповнюється в міру проходження.

| Папка                         | Міні-проєкт                      |
| ----------------------------- | -------------------------------- |
| `src/components/Theory-pr`    | Теорія на практиці (`useState`)  |
| `src/components/Theory-pr2`   | Теорія на практиці, частина 2    |
| `src/components/Cocktails-pr` | Застосунок коктейлів             |

### Гілки — задачі для повторного проходження

В окремих гілках зберігаються задачі та компоненти, до яких я хочу повернутися
й розв’язати знову, щоб закріпити матеріал. Гілки **не мерджаться** в `main`.

- **`task-XX-назва`** — умова задачі (README) на чистому шаблоні. Цю гілку я не
  змінюю.
- **`task-XX-назва-tryN`** — моя спроба розв’язання, створена від гілки задачі.

## Хочеш розв’язати задачу й показати мені?

Із задоволенням перевірю твоє рішення. Як це зробити:

1. Зроби **Fork** цього репозиторію (кнопка праворуч угорі на GitHub).
2. Склонуй свій форк і перейди в гілку задачі:
   ```bash
   git clone https://github.com/<твій-нік>/react.git
   cd react
   git checkout task-01-cafe-feedback
   git checkout -b task-01-cafe-feedback-<твій-нік>
   ```
3. Розв’яжи задачу за README, закоміть і запуш гілку у свій форк:
   ```bash
   git push -u origin task-01-cafe-feedback-<твій-нік>
   ```
4. Відкрий **Pull Request** у цей репозиторій:
   - **base:** `task-01-cafe-feedback` (гілка задачі, **не** `main`);
   - **compare:** твоя гілка з форку;
   - у назві вкажи: `Рішення task-01 — <твій-нік>`.
5. Я перегляну код і залишу коментарі прямо в PR.

PR **не мерджиться**, щоб гілка задачі залишалася чистою для наступних
проходжень. Після рев’ю я закрию PR, а твоє рішення залишиться у твоєму форку.
